File Integrity Monitor

What is this?

This tool uses Cryptographic Hashing (SHA256) to create a unique "Digital Secure Checksum" of your files. If a file is secretly modified by malware or an intruder, its Secure Checksum will change, and this monitor will immediately detect the tampering.
